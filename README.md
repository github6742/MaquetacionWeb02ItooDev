# DESCRIPCION:
Comienza con una maqueta realizada en photoshop de la pagina con las secciones inicio, quienes somos, servicios, contactenos.
Luego va armando el proyecto en base a esa imagen.

Arma los htmsl, utiliza una hoja de estilos, y luego:

Recorta las partes de esa imagen, y la va pegando en el codigo, luego va armando las cajas en css que van pisando y reemplazando esa imagen.
Es decir utiliza la imagen pegada en el html o en el css para utilizar como plano.

En css no utilza flex, no utiliza grid, todas posiciones relativas o absolutas de la caja padre.

En css utiliza id, y para seleccionar y armar las cajas realiza todo el camino de seleccion o especifidad.
